# Start/Stop Insight

Full-screen, read-only ID7 dashboard for the DDE's five native MSA decision words. It records the last ten observed state transitions locally and ranks the electrical consumer channels available on the D70/D75/D83 diesel DDE family.

No diagnostic write, routine, actuator, reset or coding request is present. Individual undocumented MSA bits are deliberately displayed by channel and bit number rather than assigned invented meanings.
